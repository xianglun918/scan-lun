Features

功能

三个问题，一天回顾。所有功能围绕一次两分钟的自省展开，不多也不少。

每日定时提醒

到点自动弹出三问表单，已答当天不重复打扰。

三问自定义

默认职场三省模板，问题文案可随时修改。

本地存储

SQLite 明文存储，数据完全留在本机，不上传、不联网。

历史回看

按日期展开查看往期记录，回看自己走过的每一天。

Markdown / CSV 导出

在历史页一键导出全量数据，Markdown 与 CSV 两种格式。

托盘常驻

关闭即隐藏，仅工作日提醒，可开机自启，安静不打扰。

How it works

使用流程

从弹出到落库，一次完整的自省只需三步。

  1. 一

    到点弹出

    每天 18:00（可改）三问表单自动弹出抢焦点；从托盘菜单也可「立即填写」。

  2. 二

    填写三问

    回答固定三问： 今日完成 今日问题与不足 明日计划

  3. 三

    保存 / 稍后 / 跳过

    保存落库当天不再打扰；稍后一小时后再弹；跳过不落库、不重弹。

Architecture

架构

双窗口 + 托盘常驻：prompt 只负责到点打断，main 负责历史回看与设置。
